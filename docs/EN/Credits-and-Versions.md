# Credits & Versions

## Project lineage

Pokémon Tactica is built from **Pokémon Heart & Soul**.

Heart & Soul itself is built on several major open-source projects:

1. **pret / pokeemerald** — Pokémon Emerald decompilation project;
2. **Modern Emerald** by resetes12;
3. **Rom Hacking Hideout / pokeemerald-expansion**;
4. **Pokémon Heart & Soul** and its contributors;
5. **Pokémon Tactica**, which adapts that base with its own gameplay, data and interface decisions.

Full upstream credits should remain preserved in the repository and final distribution.

## Pokémon Heart & Soul

Heart & Soul provides the Johto foundation used by Tactica:
- regions and progression;
- scripts;
- maps;
- GSC/HGSS mechanics adapted to the GBA engine;
- QoL systems;
- visual/audio foundation;
- pokeemerald-expansion integration.

Tactica is not intended to hide that work; it is a fork built on top of it.

## Tactica — V1

V1 focuses on:

- HARD/NORMAL;
- expanded starters;
- second starter through the Egg;
- Level Caps;
- Training NPC;
- native speed;
- audio settings;
- custom Pokémon;
- learnsets;
- encounters;
- HARD boss teams;
- adapted AI;
- strategic shops;
- EN/FR support;
- light visual finishing;
- player wiki.

## Version status

### V1 — in development

Goal: reach a stable end-to-end tested release that can also serve as a reusable Tactica base.

Before stable release:
1. data/engine integration;
2. build + tests;
3. early-game manual test;
4. visual finishing;
5. RC;
6. full playthrough;
7. corrections;
8. final regression.

### V2 — planned later

Explicitly deferred:
- major visual overhaul;
- Shiny Only;
- other extensions that should not delay a stable V1.
