Roadmap

V1 targets a stable end-to-end experience from Johto through Kanto and the second League, with Tactica systems integrated and a reliable wiki for team preparation.

V1 — stabilization order

1. CORE / gameplay
Bosses, rival, Rocket, caps, Mega Evolution, starters/Egg and blocking regressions.
2. Encounters / progression
Pokédex coverage, pre-League access, habitats and evolutionary stages.
3. ROM UI / UX
Summary, battle HUD, menus and shops.
4. RC
Full build, tests, validators, synchronization checks and technical regression.
5. Wiki
Final data-alignment, FR/EN and browsing pass before stable release.

Fine balance is adjusted during validation playthroughs and should not block technical stabilization of the systems.

Before stable release

V1 is only considered stable after data/engine integration, complete build and tests, first RC, a full playthrough, fixes from that run and a final regression pass.

V2 — later

V2 is deliberately separated so it does not delay a stable V1. It may include a larger visual overhaul, Shiny Only and other non-essential extensions or challenges.
