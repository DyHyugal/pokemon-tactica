Roadmap

Pokémon Tactica V1 has entered its finishing phase. The major gameplay systems are now in place; the remaining work is mostly about polishing the interface, validating everything together in a fresh ROM and locking a stable build that can be played from start to finish.

Already integrated

Core gameplay

Native x1–x4 speed, independent audio, Shiny Rate, starter selection, second starter through the Egg, solo evolutions and the Training NPC.

Progression and encounters

Level Caps, four-slot encounter redistribution, Safari, Headbutt and encounter levels aligned with the real first access to each area.

Strategic battles

New Gym Leader teams, an evolving rival, progressive Team Rocket rosters, boss Mega Evolutions and player access to the Mega Ring after Morty.

Team preparation and wiki

Specialized shops, training services, detailed Pokédex, Locations and the new Routes & Cities guide.

V1 finishing work

ROM UI / UX

Final work on the Summary screen, custom shops, battle panels and window polish so the black / red / gray identity stays coherent everywhere.

In-game validation

Systems already covered automatically still need to be checked together in one fresh ROM: starter flow, rival, Route 36, Morty's Mega, Mega Ring, shops and the full progression path.

Before V1 release

Test candidate

Clean build, green CI on the exact same SHA, full manual checklist and an owner run without asking for already-known defects to be rediscovered.

Stabilization

Fix only regressions observed during that run, replay targeted checks and freeze the stable V1.

After V1

Features that should not delay the first stable release — including Shiny Only, a dedicated French ROM and larger visual or content iterations — move into the V1.1 / V2 cycle.
