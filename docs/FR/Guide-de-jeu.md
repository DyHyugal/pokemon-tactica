# Guide de jeu

## Difficulté

HARD par défaut ; NORMAL conserve le même contenu.

## Settings

Mode / Features / Randomizer / Nuzlocke / Difficulty / Challenges · B = Save & Exit · x1/x2/x3/x4 · MUET/20/40/60/80/100% · shiny 1/8192 à 1/1.

## Rencontres

Quatre slots 30/30/30/10 par table. La pêche a un pool par table ; les cannes en contrôlent l'accès. L'assistant d'entraînement couvre EXP, IV, EV/reset, nature, talent et bonheur.
