# Adversaires officiels — recherche pour Pokémon Tactica

Recherche du 10 octobre 2026 fondée sur Poképédia : **54 personnages, 55 fiches, 142 compositions et variantes**. Les équipes, niveaux, objets, talents et attaques sont distingués selon les opus et les formats.

**[Lire le rapport complet directement sur GitHub](adversaires-officiels.md)**

Pour consulter la version interactive avec recherche et filtres, [télécharger la page HTML](https://github.com/DyHyugal/pokemon-tactica/raw/refs/heads/research/adversaires-officiels/docs/research/adversaires-officiels/adversaires-officiels.html), puis ouvrir le fichier téléchargé dans un navigateur. La page fonctionne hors ligne. GitHub affiche le code HTML si vous ouvrez sa page de fichier ; utilisez le téléchargement ci-dessus pour obtenir la page interactive.

**[Télécharger toute la recherche en ZIP](https://github.com/DyHyugal/pokemon-tactica/raw/refs/heads/research/adversaires-officiels/docs/research/adversaires-officiels/archive-complete.zip)**. L’archive contient le rapport, la page interactive, le tableur, les données structurées, les scripts de reproduction et les 80 pages sources conservées avec leurs empreintes.

Le [tableur des équipes](equipes.csv) utilise UTF-8 et le séparateur point-virgule. Les [données structurées](equipes-selectionnees.json) permettent de réutiliser la sélection.

Cette branche conserve des recherches et des propositions pour les futurs combats mystère. Elle ne modifie ni le jeu, ni les spécifications, ni la ROM candidate. Les niveaux sont ceux des jeux officiels et ne sont pas des caps proposés pour Tactica.
