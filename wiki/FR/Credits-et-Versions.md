# Crédits & Versions

## Héritage du projet

Pokémon Tactica est construit à partir de **Pokémon Heart & Soul**.

Heart & Soul est lui-même construit sur plusieurs projets open source majeurs :

1. **pret / pokeemerald** — projet de décompilation de Pokémon Emerald ;
2. **Modern Emerald** de resetes12 ;
3. **Rom Hacking Hideout / pokeemerald-expansion** ;
4. **Pokémon Heart & Soul** et ses contributeurs ;
5. **Pokémon Tactica**, qui adapte cette base avec ses propres choix de gameplay, données et interface.

Les crédits complets des projets amont doivent rester conservés dans le repository et la distribution finale.

## Pokémon Heart & Soul

Heart & Soul fournit la base Johto de Tactica :
- régions et progression ;
- scripts ;
- cartes ;
- mécaniques GSC/HGSS adaptées au moteur GBA ;
- fonctionnalités QoL ;
- base graphique et sonore ;
- intégration avec pokeemerald-expansion.

Tactica n'a pas vocation à masquer ce travail : il s'agit d'un fork qui construit dessus.

## Statut des versions

### V1 — en développement

Objectif : obtenir une version stable, testée de bout en bout et réutilisable comme base Tactica.

Avant release stable :
1. intégration data/moteur ;
2. build + tests ;
3. test manuel du début de jeu ;
4. finition graphique ;
5. RC ;
6. playthrough complet ;
7. corrections ;
8. régression finale.

### V2 — prévu plus tard

Éléments explicitement repoussés :
- refonte graphique majeure ;
- Shiny Only ;
- autres extensions qui ne doivent pas retarder la V1 stable.
