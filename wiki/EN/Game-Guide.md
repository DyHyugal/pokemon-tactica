# Game Guide

## Difficulty

HARD by default; NORMAL keeps the same content.

## Settings

Mode / Features / Randomizer / Nuzlocke / Difficulty / Challenges · B = Save & Exit · x1/x2/x3/x4 · MUTE/20/40/60/80/100% · shiny 1/8192 à 1/1.

## Encounters

Four 30/30/30/10 slots per table. Fishing has one pool per table; rods gate access. The training assistant covers EXP, IVs, EVs/reset, nature, ability and friendship.
